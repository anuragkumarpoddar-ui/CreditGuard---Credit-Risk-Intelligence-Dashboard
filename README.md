## Project Overview

**CreditGuard** is an interactive Power BI dashboard designed to analyze credit card data and support data-driven credit risk assessment. It aims to turn raw data into meaningful insights through interactive visualizations, KPIs, and analytical reporting.

## Project Objectives

- Analyze credit card data and customer risk indicators.
- Identify patterns and trends relevant to credit risk.
- Present key metrics through interactive dashboards.
- Support informed business decisions using data visualization.

## Tools & Technologies

- **Power BI** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Calculated measures and KPIs
- **Data Analytics** — Trend analysis and insight generation

## Key Features

- Interactive KPI cards and visual reports
- Credit risk analysis and data exploration
- Customer and credit-related metric analysis
- Dynamic filtering for deeper insights
- Business-focused visual storytelling

## Business Value

CreditGuard demonstrates how Power BI can transform credit card data into an interactive analytical solution, helping users explore risk-related patterns, monitor key indicators, and support better-informed decisions.
